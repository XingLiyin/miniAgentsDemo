HLD 总体方案 — §3 跨域关系设计

3.1 IP 与云核对接关系

涉及 12 条互联链路，采用 SRv6 Policy 承载云业务。各节点通过 BGP-LU 建立 EBGP 邻居，VPN 实例通过 route-policy 引流。

3.2 光层带宽绑定逻辑

IP 层互联绑定至 OTN 100G 波道，GMPLS 信令协同管理。

  • GZ 方向：3×100G，充足
  • SZ 方向：2×10G，⚠️ 需扩容

3.3 跨域风险边界

跨域操作需 IP 与光层团队同步协调，MOP 中需明确协调节点及回退联系人。
