## 单板合并算法

1. 统计 A机房所有业务单板的使用端口数之和，用公式计算最少单板数
2. 若当前单板数已等于最少单板数，无需合并，直接生成B机房配置表
3. 若需要合并，重复执行以下操作直到剩余单板数等于最少单板数：
   - 找出**使用端口数最少**的单板，作为被合并单板
   - 找出**空闲端口数最多**的单板，作为目标单板（有多个相同时任选一个）（空闲端口数 = 16 − 使用端口数）
   - 将被合并单板的业务迁移至目标单板，目标单板使用端口数相应增加
   - 被合并单板标记为退出，不出现在B机房配置中
4. 对每块保留单板，按以下规则填写B机房配置：

| 字段 | 填写规则 |
|------|----------|
| 槽位 | 与A机房槽位号保持一致 |
| 单板类型 | GPON单板 → H907CGHF；10GPON单板 → 保留原型号不变 |
| 端口类型 | 统一填 10GPON |
| 单板端口数 | 固定填 16 |
| 使用端口数 | 未合并单板：与A机房一致；合并后保留单板：更新为合并后的值 |
