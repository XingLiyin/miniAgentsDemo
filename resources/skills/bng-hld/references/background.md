## 背景知识

### 搬迁场景

本项目将 BNG（宽带网络网关）设备的业务由**旧机房迁移至新机房**。新机房统一采用中国移动集采框架规范的华为 BNG 设备承接全部业务，旧机房设备搬迁完成后退网。

### 单板类型

BNG 为机框式设备，本 skill 仅关注以下业务单板：

| Type | 说明 |
|------|------|
| LPU | 线路处理板，可插子卡（PIC），子槽位以 Card 列表示 |
| PIC | 插入 LPU 子槽位的灵活插卡 |
| 业务板 | 专用功能板（如 VSUF、PSSU） |

### EOX / EOM 说明

EOM（停止销售）和 EOS（停止支持）单板需在搬迁时按移动集采框架进行 1:1 替换，替换型号见 `references/procurement_replacement.xlsx`。

---

### 为什么剔除未使用槽位？

旧机房部分槽位长期无业务接入，端口协议状态全部为 down。迁入新机房时无需为这些空槽位配板——带入新机房只会增加硬件采购成本，而不承载任何业务价值。

### 为什么 EOX 单板必须替换？

EOM/EOS 单板已停产停售，新机房无法采购备件，出现故障后将无法维修。中国移动集采框架提供了功能等价的在产替代型号，统一替换后可保障设备长期可维保性。
