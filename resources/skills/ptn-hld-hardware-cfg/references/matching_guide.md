## LPU 单板匹配规则

当设备需要 EOX 替换时，从 `{{CANDIDATES}}` 列表中为A机房每块 LPU 选择对应的 B 机房单板。

### 匹配优先级（从高到低）

| 优先级 | 判断标准 | 说明 |
|--------|----------|------|
| 1 | 端口数量完全一致 | 原为16口 → 优先找16口的候选单板 |
| 2 | 速率向上兼容 | GE → 优先选 10GE/GE；10GE → 优先选 10GE/GE |
| 3 | 功能类型一致 | Switching → Switching；Routing → Routing |

### 匹配步骤

1. 从A机房单板描述中提取端口数（如"16-Port"→16）和速率关键词（如"10GE/GE"、"GE/FE"）
2. 在 `{{CANDIDATES}}` 中筛选端口数相同的候选单板
3. 若只有一个候选 → 直接选取
4. 若有多个候选 → 按速率兼容性选最优（能覆盖原速率的最低规格）
5. 若无端口数匹配的候选 → 选端口数最接近且≥原端口数的单板，并在输出中标注 `⚠️ 端口数不匹配，请人工确认`

### 示例

| A机房单板描述 | 匹配逻辑 | B机房单板描述 |
|--------------|----------|--------------|
| 16-Port GE/FE LPU | 端口数=16，速率GE/FE → 找16口且支持GE | 16-Port 10GE/GE LPU（向上兼容） |
| 8-Port 10GE LPU | 端口数=8，速率10GE → 找8口10GE | 8-Port 10GE/GE LPU（向上兼容） |
| 24-Port GE/FE LPU | 端口数=24，速率GE/FE → 找24口GE | 24-Port 10GE/GE LPU（向上兼容） |
