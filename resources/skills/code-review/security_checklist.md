# 安全审查清单（Level 3 资源）

## 输入验证

- [ ] 所有用户输入是否经过验证和清理？
- [ ] 是否使用参数化查询防止 SQL 注入？
- [ ] 文件上传是否限制类型和大小？
- [ ] 是否对输出进行 HTML 转义以防止 XSS？

## 认证与授权

- [ ] 是否对所有敏感端点进行认证检查？
- [ ] 是否实现最小权限原则？
- [ ] Session/Token 是否安全存储和传输？
- [ ] 是否有防暴力破解机制（速率限制）？

## 数据保护

- [ ] 敏感数据是否加密存储？
- [ ] 是否使用 HTTPS？
- [ ] 日志中是否避免记录敏感信息？
- [ ] 是否有硬编码的密钥或密码？

## 依赖安全

- [ ] 第三方依赖是否有已知漏洞？
- [ ] 是否固定了依赖版本？

## 错误处理

- [ ] 错误信息是否暴露了过多内部信息？
- [ ] 是否存在未处理的异常？
