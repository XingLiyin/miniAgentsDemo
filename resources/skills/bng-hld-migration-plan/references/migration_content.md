# 新垦机房BNG搬迁方案：拓扑不变，利旧IP地址池，站点搬迁

## 割接关键步骤

**BNG一次性割接，BNG下挂OLT量较少（20-30以内）**

---

## 客户依赖

1. 支持协调新BNG与计费认证、DHCP等业务系统对接
2. BNG下挂OLT分多次割接时候，支持提供新的业务地址段
3. 协调大企业用户配合割接、进行业务测试

---

## 说明

1. 现网BNG部署方案为双机冷备
2. 站点B为被搬迁机房，站点C为新建替代机房
3. 新建机房建议使用新BNG搬迁旧机房BNG，后续循环使用被替换下的BNG

---

## 关键步骤

| 序号 | 关键步骤 | 关键风险与依赖 |
| ---- | -------- | -------------- |
| 1 | 新机房BNG上电，集成对接到CMNET城域网，设备间互联使用新IP地址 | 新建BNG需经华为评估，硬件、license等可满足与现网BNG双机冷备 |
| 2 | 新建BNG3对接移动认证、计费系统等，配置完成BRAS冷备基本配置，使用全新互联IP地址 | 1、需客户协调现网计费、DHCP等业务系统与新站点BNG完成对接集成；2、割接前需新站点现场测试业务终端经BNG100%成功 |
| 3 | BNG2基于OLT接口下线用户，将OLT链路连接到BNG3，将OLT上线到新BNG3，用户地址池利旧，一次性完成BNG2→BNG3替换 | 路由发布与控制，OLT上承载业务多样，有组播、静态、专线用户等，搬迁过程业务易受损 |
| 4 | 拆除BNG2，用作下一个机房搬迁 | — |
