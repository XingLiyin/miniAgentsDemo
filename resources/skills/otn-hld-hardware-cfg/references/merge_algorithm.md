## B机房推理算法

### 输入数据

| 文件 | 用途 |
|------|------|
| `references/nms_data.xlsx` | A机房现网设备与单板配置 |
| `references/lifecycle.xlsx` | 各设备类型的生命周期状态 |
| `references/procurement.xlsx` | 客户集采可用的设备与单板清单 |

---

### 推理步骤

**阶段一：读取A机房配置**

从 `nms_data.xlsx` 读取所有行，直接作为 A 机房配置表输出（设备类型 / 单板类型 / 单板数量）。

**阶段二：判断每行设备的生命周期**

对 A 机房表中每一行，查询 `lifecycle.xlsx`，找到对应设备类型的生命周期状态：
- 状态为 **GA** → 该行设备类型和单板类型保持不变，直接复制到 B 机房表
- 状态为 **EOS** → 进入阶段三替换流程

**阶段三：EOS设备单板替换**

对每条 EOS 设备的单板，在 `procurement.xlsx` 中寻找替代单板，规则如下：

1. 提取当前单板短名称：单板型号由"硬件版本前缀 + 短名称"组成，以末尾对齐方式取功能标识部分（例：`V3T220` 短名称为 `T220`，`S7N402` 短名称为 `N402`）
2. 在集采清单所有单板型号中，找末尾最长公共后缀完全匹配的单板（精确匹配，不做模糊判断）
3. 取匹配的集采单板型号作为 B 机房单板型号
4. 取对应集采单板所属的设备类型作为 B 机房设备类型
5. 单板数量保持 1:1 不变

**阶段四：组装B机房配置表**

将 GA 行（直接复制）和 EOS 替换行合并，按原始 A 机房行顺序排列，输出 B 机房配置表。

---

### 注意事项

- 同一设备类型下的不同单板行，分别独立判断是否需要替换
- 若集采清单中找不到匹配短名称，在输出中标注 `[待确认]` 并保留原型号
- 单板数量列全程保持与 A 机房一致，不做任何合并或拆分
