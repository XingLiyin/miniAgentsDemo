# 背景说明

网管导出的 ONU 状态表包含以下字段：

| 字段 | 说明 |
|------|------|
| 网元名称 | OLT 设备标识 |
| 框 / 槽 / 端口 | PON 口物理位置，每槽固定有 0–15 共 16 个端口 |
| ONU ID | 同一端口下可接多个 ONU，从 0 开始编号 |
| 状态 | ONU 当前状态，"在线"表示正常在用 |

## 四类端口定义

| 序号 | 类别 | 判断规则 |
|------|------|---------|
| 1 | 端口 UP 且有业务 | 该端口下存在至少一条状态为"在线"的 ONU 记录 |
| 2 | 端口 UP 但无业务 | 无法从表中判断，固定填 0 |
| 3 | 端口 Down 但配置有业务 | 该端口下有 ONU 记录，但无任何"在线"状态 |
| 4 | 端口 Down 且无业务 | 该端口在表中完全不存在（每槽 0–15 中的缺失端口） |
