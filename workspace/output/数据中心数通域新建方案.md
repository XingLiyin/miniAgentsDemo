# 数据中心数通域新建方案设计文档

## 一、项目概述

### 1.1 项目背景
本项目为某银行数据中心机房新建工程，旨在构建一个安全、可靠、可扩展的数通网络基础设施，满足银行基础金融业务的承载需求。

### 1.2 设计目标
- **规模**：约 10 个机柜
- **业务类型**：银行基础金融业务（核心交易系统、渠道接入、后台管理等）
- **设备品牌**：华为 NE 系列路由器及配套设备
- **建设原则**：高可靠性、高可用性、安全性、易管理性、可扩展性

### 1.3 设计依据
- 《金融行业信息系统网络安全等级保护基本要求》
- 《商业银行数据中心监管指引》
- 华为官方最佳实践指导

## 二、网络架构设计

### 2.1 总体拓扑结构

采用经典的三层架构：**核心层 → 汇聚层 → 接入层**

```
                    ┌─────────────────────────────────────────────┐
                    │              互联网出口区                   │
                    │     ┌───────────┐    ┌───────────┐         │
                    │     │  防火墙 A  │◄──►│  防火墙 B  │         │
                    │     └─────┬─────┘    └─────┬─────┘         │
                    └───────────┼────────────────┼───────────────┘
                                │                │
                        ┌───────▼────────────────▼───────┐
                        │          核心交换区            │
                        │     ┌───────────┐    ┌───────────┐     │
                        │     │ 核心交换机 A│◄──►│核心交换机 B│     │
                        │     │  (NE40E)   │    │  (NE40E)   │     │
                        │     └─────┬─────┘    └─────┬─────┘     │
                        └───────────┼────────────────┼─────────────┘
                                    │                │
                    ┌───────────────▼────────────────▼───────┐
                    │           汇聚交换区                    │
                    │     ┌───────────┐    ┌───────────┐     │
                    │     │汇聚交换机 A│◄──►│汇聚交换机 B│     │
                    │     │  (CE6863) │    │  (CE6863) │     │
                    │     └─────┬─────┘    └─────┬─────┘     │
                    └───────────┼────────────────┼─────────────┘
                                │                │
              ┌─────────────────┴───┬────────────┴────────────┬────────────┐
              ▼                     ▼                        ▼            ▼
        ┌──────────┐         ┌──────────┐              ┌──────────┐  ┌──────────┐
        │接入交换机│         │接入交换机│              │接入交换机│  │接入交换机│
        │(S6730)   │         │(S6730)   │              │(S5735)   │  │(S5735)   │
        └────┬─────┘         └────┬─────┘              └────┬─────┘  └────┬─────┘
             │                    │                         │             │
       ┌─────┴────────┐      ┌─────┴────────┐        ┌─────┴──────┐ ┌────┴────┐
       │ 服务器区 1-4  │      │ 服务器区 5-6  │        │ 办公终端   │ │ 网管区  │
       │  (10GE 上联)  │      │  (10GE 上联)  │        │  (1GE 接入)  │ │        │
       └──────────────┘      └──────────────┘        └───────────┘ └─────────┘
```

### 2.2 分层功能说明

| 层级 | 功能定位 | 关键特性 |
|------|----------|----------|
| **核心层** | 全互联高速转发、跨区流量调度 | 100G 端口、高密度 10GE、冗余电源风扇、硬件级双机热备 |
| **汇聚层** | 区域流量聚合、策略控制点 | 支持 ACL/QoS/VRF、链路聚合、VRRP 冗余 |
| **接入层** | 终端/服务器接入、边缘安全 | PoE+ 供电、ACL 访问控制、环路防护、端口隔离 |

### 2.3 关键链路带宽规划

| 链路方向 | 推荐带宽 | 冗余方式 |
|----------|----------|----------|
| 核心 ↔ 互联网防火墙 | 10G × 2 | LACP 聚合 |
| 核心 ↔ 汇聚 | 10G × 2 / 40G × 1 | ECMP 负载均衡 |
| 汇聚 ↔ 接入 | 10G × 2 | LACP 聚合 |
| 接入 ↔ 服务器 | 10G SFP+/RJ45 | 根据服务器配置 |
| 接入 ↔ 终端 | 1G RJ45 / 10G SFP28 | - |

### 6.2 关键安全措施

#### 6.2.1 网络访问控制（ACL）

在汇聚/核心交换机上部署如下基本访问控制规则：

```
# 示例 ACL 规则（以华为命令格式）
acl number 3000  // 高级 ACL
 rule 5 permit tcp source any destination 10.150.2.0 0.0.0.255 destination-port eq 80
 rule 10 permit tcp source any destination 10.150.2.0 0.0.0.255 destination-port eq 443
 rule 15 deny ip source 10.150.2.0 0.0.0.255 destination 10.100.0.0 0.0.255.255
 rule 20 permit ip source 10.100.0.0 0.0.255.255 destination 10.100.0.0 0.0.255.255
 rule 25 deny ip source any destination any
```

#### 6.2.2 防火墙策略要点

| 方向 | 默认动作 | 开放策略 |
|------|----------|----------|
| 外→内 | Deny 所有 | 仅允许可信业务端口 |
| 内→外 | Allow 所有 | 限制异常流量 |
| 内→内 | Deny 所有 | 按业务需求白名单 |

#### 6.2.3 认证和授权

- 设备登录：AAA + TACACS+/RADIUS 集中认证
- SSH v2 加密登录，禁用 Telnet
- 本地账户：强密码策略（大小写字母 + 数字 + 特殊字符，长度≥12）

### 6.3 合规性要求

| 等级保护项 | 实施措施 |
|------------|----------|
| 三级等保 | 物理安全、网络安全、主机安全、应用安全、数据安全全维度防护 |
| 行业监管 | 符合银保监会《商业银行信息科技风险管理指引》要求 |
| 审计要求 | 日志留存不少于 6 个月，支持远程审计取证 |

## 七、高可用性设计

### 7.1 设备级冗余

| 层级 | 冗余方式 | 切换时间 |
|------|----------|----------|
| 核心路由器 | 1+1 HA 双机热备 | <50ms |
| 汇聚交换机 | 双机堆叠/iStack | <50ms |
| 接入交换机 | 上行双归接入 | <1s |
| 防火墙 | Active-Standby HA | <1s |

### 7.2 链路冗余设计

#### 7.2.1 冗余拓扑

```
                    【服务器/终端】
                       │
            ┌──────────┴──────────┐
            ▼                     ▼
        ┌──────────┐         ┌──────────┐
        │ 接入设备 A │         │ 接入设备 B │
        └────┬─────┘         └────┬─────┘
             │                   │
      ┌──────┴───────────────────┴──────┐
      │         (LACP/Eth-Trunk)        │
      ▼                                 ▼
┌─────────────────┐          ┌─────────────────┐
│     汇聚设备 A    │◄────────►│     汇聚设备 B    │
│  (iStack/堆叠)   │    10G   │  (iStack/堆叠)   │
└────────┬────────┘          └────────┬────────┘
         │                            │
    ┌────┴────────────────────────────┴────┐
    │         (ECMP 多路径负载)              │
    ▼                                      ▼
┌─────────────────┐          ┌─────────────────┐
│     核心设备 A    │◄────────►│     核心设备 B    │
│   (SSN 双主控)   │    40G   │   (SSN 双主控)   │
└─────────────────┘          └─────────────────┘
```

#### 7.2.2 链路聚合配置

```
# 接口绑定示例
interface Eth-Trunk 10
 mode lacp-static
 trunkport GigabitEthernet 1/0/1 to 1/0/2
 description Link-to-Aggregation-Switch
```

### 7.3 协议级高可用

#### 7.3.1 VRRP 虚拟网关

```
# VLANIF 接口 VRRP 配置示例
interface Vlanif 1001
 ip address 10.100.1.253 255.255.255.0
 vrrp vrid 1 virtual-ip 10.100.1.254
 vrrp vrid 1 priority 120          # 主设备优先级高
 vrrp vrid 1 preempt-mode timer delay 3
 vrrp vrid 1 track interface GigabitEthernet 1/0/1 reduced 30
```

#### 7.3.2 OSPF 快速收敛

```
# OSPF 加速配置
ospf 1 router-id 1.1.1.1
 import-route direct
 area 0
  network 10.10.0.0 0.0.255.255
  network 10.100.0.0 0.0.255.255
  
# 启用 BFD 加速故障检测
bfd all-interface enable
ospf 1
 bfd all-interface enable
 timer fast-convergence
```

#### 7.3.3 设备级备份机制

| 组件 | 备份策略 |
|------|----------|
| 配置文件 | 每日自动备份至 FTP/TFTP 服务器 |
| 软件版本 | 保留两个稳定版本现场备件 |
| 运行状态 | 实时同步至对端设备 |

### 7.4 故障恢复预案

| 故障类型 | 影响范围 | 恢复方式 | 预计时间 |
|----------|----------|----------|----------|
| 单设备故障 | 部分业务 | 主备切换，<1% 丢包 | <1min |
| 单板故障 | 对应端口 | 自动倒换 | <50ms |
| 链路故障 | 该链路流量 | ECMP/LACP 重计算 | <50ms |
| 电源故障 | 该设备 | 冗余电源供電 | 0ms |
| 整机断电 | 单节点业务 | 对端接管全部流量 | <1s |

| IPv4 地址池 | 约 5000 个 | ~50% | 80% |
| VLAN 数量 | 约 20 个 | ~20% | 80% |

### 8.2 扩展性设计

#### 8.2.1 横向扩展能力

- **接入层扩展**：可通过增加 S6730/S5735 设备扩展，支持最多 50+ 接入交换机
- **汇聚层扩展**：CE6863 系列支持 iStack 堆叠，可纵向扩容至 9 台设备
- **核心层扩展**：NE40E-X8 机箱支持灵活槽位，可按需增加线卡

#### 8.2.2 垂直扩容能力

- **带宽升级路径**：1GE → 10GE → 40GE → 100GE → 400GE
- **端口密度提升**：支持 19 英寸标准机架部署，单机柜可容纳 40U 设备

### 8.3 三年扩容预测

| 阶段 | 规模增长 | 扩容方案 | 预算预估比例 |
|------|----------|----------|--------------|
| Year 1 | 基准规模 | 已完成 | 100% |
| Year 2 | +20% | 增配 2 台接入交换机 | +15% |
| Year 3 | +40% | 新增 1 台汇聚交换机、优化核心带宽 | +30% |

## 十、验收与运维建议

### 10.1 验收检查项

| 类别 | 检查项 | 验收标准 |
|------|--------|----------|
| 设备 | 设备外观、标识、配件 | 齐全完好、无损坏 |
| 连线 | 线缆连接、标签 | 正确连接、标识清晰 |
| 配置 | IP 地址、路由、VLAN | 与设计方案一致 |
| 连通性 | Ping、Tracert 测试 | 各区域可达 |
| 冗余 | 拔线/断电测试 | 切换正常、无业务中断 |
| 性能 | 吞吐量、时延测试 | 满足设计要求 |
| 安全 | ACL、防火墙策略 | 策略生效、访问控制正常 |

### 10.2 运维管理建议

1. **监控体系**：部署 SNMP/NTP/Syslog，对接统一网管平台
2. **告警管理**：建立分级告警机制（紧急、重要、一般、提示）
3. **定期巡检**：每周远程巡检，每月现场巡检
4. **变更管理**：严格执行变更流程，记录操作日志
5. **应急预案**：制定常见故障应急手册，定期演练
